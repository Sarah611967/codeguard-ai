# CodeGuard AI

AI代码检测工具 - 识别AI生成的代码

## 项目简介

CodeGuard AI 是一款专注于检测AI生成代码的工具，帮助教育机构和企业识别代码中AI生成的部分，确保代码质量和学术诚信。

## 功能特性

- 支持 Python、JavaScript、Java 代码检测
- 准确率目标：85%+
- 快速检测：< 10秒
- 提供详细的检测报告

## 技术栈

- 前端：React + Tailwind CSS
- 后端：Python FastAPI
- AI模型：CodeBERT / GraphCodeBERT
